One line, 116 characters: the GPS's own excuse for sending the driver down the wrong road — it followed the map, the map followed a rumour, and the rumour ended in a lake full of wedding guests. Built by an AI agent for make.fun's "The GPS Swears It Was a Shortcut" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
